# FLOW UI/UX direction

The current UI direction is intentionally light and operational.

- Android login is preserved from the original project, including its animation and visual composition.
- Other Android screens use restrained Material 3 surfaces, calm spacing, and green accents.
- Web uses a soft-light workspace with low contrast background layers, white operational surfaces, and restrained green accents.
- Live Board shows every `IN_PROGRESS` trip, newest GPS/activity update first.
- Tracking maps use MapLibre + OpenStreetMap and do not require Google Maps Platform billing or API keys.
- Tracking maps follow the newest GPS point; dragging the map temporarily disables auto-follow and a recenter control restores it.
